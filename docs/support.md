# 쇠질 지원

쇠질은 로그인 없이 이 폰에만 기록하는 헬스 로그 앱입니다.

## 자주 묻는 질문

**기록이 어디에 저장되나요?**
기기 안에만 저장됩니다. 서버로 보내지 않습니다. 기기를 바꾸기 전에 프로필 탭에서 "기록 내보내기"로 JSON을 저장해 두세요.

**운동 중에 앱이 꺼졌어요.**
체크한 세트는 그때그때 저장됩니다. 오늘 탭에 다시 들어오면 이어서 진행됩니다.

**세트가 완료로 기록되지 않아요.**
세트 오른쪽 동그라미를 눌러야 완료로 기록됩니다. 아래 큰 버튼은 남은 세트를 한 번에 완료 처리합니다.

**같은 프로그램을 다시 시작했는데 무게가 그대로예요.**
의도된 동작입니다. 진행을 유지합니다. 처음부터 시작하려면 루틴 탭에서 프로그램을 길게 눌러 "처음부터 다시 시작"을 고르세요.

**1RM을 바꿨는데 무게가 안 바뀌어요.**
5/3/1과 nSuns는 1RM 기반 TM을 바로 다시 계산합니다. 6일 근비대, PPL, PHUL, 상하체 분할, 스타팅 스트렝스는 세트 무게로 진행하므로 1RM과 무관합니다.

**휴식 타이머 알림이 안 와요.**
설정 > 알림 > 쇠질에서 알림을 허용해 주세요. 앱이 켜져 있으면 알림 없이도 화면에 타이머가 표시됩니다.
